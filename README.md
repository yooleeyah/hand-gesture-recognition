## Высокоточная модель распознавания жестов

**Цель:** Создать модель глубокого обучения, способную точно распознавать жесты рук. Она может быть использована в различных приложениях, таких как управление устройствами без касания, виртуальная реальность, игры и помощь людям с ограниченными возможностями. 

**Преимущества:**
* *Высокая точность:* Модель достигает точности 97.71% на тестовом наборе данных.
* *Эффективная архитектура:* Использование ResNet обеспечивает высокую производительность при относительно небольшом размере модели.
* *Готовность к интеграции:* Модель может быть легко интегрирована в различные приложения.

**Данные:** Модель обучена на наборе данных Hand Gesture Recognition Database, содержащем изображения 10 различных жестов.

**Метод:** Использована архитектура ResNet, оптимизированная для распознавания жестов, Adam optimizer и cross-entropy loss function.

**Результаты:** На тестовом наборе модель показала высокую точность (recall: 97.70%, F1-мера: 97.71%, precision: 97.87%)

**Технологии:** Python (numpy, PyTorch, matplotlib, sklearn)
